# QR Maker (Flet)

A simple cross-platform **QR Code Generator App** built with **Python** and **Flet**.  
It allows you to type or paste text and instantly generate a scannable QR code.  
On Android, the app can also appear in the **Share sheet** so that text shared from other apps automatically turns into a QR code.

---

## Features

- Generate QR codes instantly from any text  
- Paste text from clipboard  
- Clear the input and regenerate quickly  
- Works on **Desktop**, **Web**, and **Android**  
- Optional: Accept shared text from other Android apps  
- Built entirely with Python — no Flutter/Dart coding needed  

---

## Tech Stack

- [Flet](https://flet.dev/) — Flutter-based UI framework for Python  
- [qrcode](https://pypi.org/project/qrcode/) — QR code generation  
- [Pillow (PIL)](https://pillow.readthedocs.io/) — image handling  
- Python 3.10+
